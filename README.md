# 🎮 20MinTillDawn-Inspired Survival Shooter

A **survival roguelike shooter** inspired by *20 Minutes Till Dawn*, built with **Java** and **LibGDX**.  
Fight endless waves of enemies, upgrade your abilities, and survive as long as you can!

---

## ✨ Features
- Smooth 2D gameplay powered by **LibGDX**
- Endless enemy waves with unique behaviors
- Upgrade system (damage, fire rate, health, movement speed, and more)
- Survival timer and scoring system
- Simple particle effects and animations
- Modular, multi-platform project structure managed with Gradle

---

## 🛠 Project Structure

This project was generated with **gdx-liftoff** and includes the following modules:

- **core** – Shared game logic
- **lwjgl3** – Desktop launcher using LWJGL3 (formerly called `desktop` in older docs)

---

## ⚙️ Requirements
- **Java 17+**
- **Gradle** (or use the included Gradle Wrapper)
